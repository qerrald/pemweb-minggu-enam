1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya!
   JavaScript adalah bahasa pemrograman yang membuat halaman web menjadi interaktif. JavaScript bisa menampilkan pesan, memvalidasi input, merespons klik tombol, dan mengubah tampilan halaman web.

2. Jelaskan secara singkat apa itu jQuery dan kegunaannya!
   jQuery adalah library JavaScript yang memperpendek penulisan kode. jQuery bisa memanipulasi elemen HTML, mengubah CSS, menangani event, membuat animasi, dan berkomunikasi dengan server.

3. Jelaskan perbedaan JavaScript dan jQuery!
   JavaScript adalah bahasa pemrograman yang membuat halaman web menjadi interaktif, sedangkan jQuery adalah library JavaScript yang memperpendek penulisan kode. JavaScript berjalan di browser tanpa tambahan apa pun, tetapi kamu harus memuat file jQuery sebelum memakainya. Untuk memanipulasi elemen HTML, mengubah CSS, dan menangani event, jQuery menawarkan sintaks yang lebih singkat daripada JavaScript biasa.
